## Open-source tools

Farborn is built with these free tools. Thank you to their authors.

| Tool | Used for |
| --- | --- |
| [Rojo](https://rojo.space) | Syncing code from Git into Roblox Studio |
| [Rokit](https://github.com/rojo-rbx/rokit) | Pinning tool versions |
| [Wally](https://wally.run) | Luau packages |
| [StyLua](https://github.com/JohnnyMorganz/StyLua) | Code formatting |
| [Selene](https://github.com/Kampfkarren/selene) | Linting |
| [Lune](https://github.com/lune-org/lune) | Running unit tests outside Studio |
