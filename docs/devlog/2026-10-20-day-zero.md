# Day zero: the repo is up

*2026-10-20 · M0 Foundation*

## What's new

Aeloria now has a home. The project is a Rojo-based Luau codebase, so all code lives in Git and
syncs into Roblox Studio. It comes with automatic checks on every change (formatting, linting,
unit tests and a full build).

## Behind the scenes

The first real systems are the save system and the wish (gacha) core. The wish core already
handles soft and hard pity and the featured 50/50, and it is covered by tests that run 100,000
simulated pulls to check the rates come out where they should.

We chose Roblox over Unreal 5: servers, payments and a huge audience come free, and a clean
cel-shaded look suits the platform.

## What's next

Locking the art style guide and the story for the first region, then a combat vertical slice:
one hero, one enemy, one minute of fighting that feels good.
