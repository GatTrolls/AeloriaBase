# Player wiki starter pages

Open a wiki on wiki.gg or Fandom at open beta. Seed it with these pages so it looks alive
from day one, then let editors from Discord grow it. Only add names after they are announced.

| Page | Contents |
| --- | --- |
| Farborn (main page) | The pitch, how to play, links to Roblox, Discord, website and Trello |
| Getting started | Controls on each platform, the first hour, tips |
| Heroes | A table of every released hero: element, weapon, rarity, role |
| Elements | The seven elements and what each is good at |
| Reactions | The reaction table from [elemental-reactions.md](../systems/elemental-reactions.md), in player words |
| Wishes | Banner types, odds, pity, and how the 50/50 works |
| World | The nations that have been released, regions and points of interest |
| Enemies | Enemy families, weaknesses, drops |
| Items | Currencies, materials, gear sets |
| Quests | Main story chapters (spoiler-tagged), side quests, hero stories |
| Events | Past and current events and their rewards |
| Codes | Active promo codes |
| Version history | One line per update, linking to the dev log |

Wiki rules to post: spoiler tags on story pages, no leaks of unreleased content, cite in-game
sources, and the community standards from the Discord.
