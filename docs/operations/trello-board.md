# Public Trello roadmap

A free Trello board players can follow. Create a board called **Farborn Roadmap**, make it
public, and copy these lists and cards. Keep it player-facing: no code talk and no spoilers.
Update it at every milestone.

## Board setup

- Visibility: Public. Comments: off (feedback goes to Discord).
- Labels: `Exploration` (green), `Combat` (red), `Heroes` (purple), `Wishes` (yellow),
  `Quality of life` (blue), `Community` (orange).
- Background: key art once it exists.
