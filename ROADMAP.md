# Roadmap

Farborn is built in milestones. Each one ends with something people can play or see.

## M0 · Foundation (now)

- [x] Rojo project, toolchain and CI
- [x] Player data service (starter)
- [x] Wish system with pity and published odds
- [x] Elemental reaction engine and damage model
- [ ] Art style guide
- [ ] Story and world locked for 1.0

## M1 · Combat slice

One minute of combat that feels great, in a test arena.

- [ ] Third-person camera, sprint, dodge, climb and glide
- [ ] One playable hero with attack chain, skill and burst
- [ ] Party of up to four with instant swap
- [ ] Elements and reactions in live combat
- [ ] One enemy type with telegraphed attacks, hit-stop and damage numbers
- [ ] Server-validated hits and cooldowns

## M2 · Core loop

- [ ] Session-locked player data and save migrations
- [ ] Hero levels, ascension, talents and gear
- [ ] Wish screen with odds, pity counter and history
- [ ] Inventory, quest tracker and the first story quest

## M3 · First nation

- [ ] The starter nation, fully explorable, with streaming
- [ ] Waypoints, chests, puzzles, a dungeon and a world boss
- [ ] Four playable heroes and three enemy families
- [ ] Co-op for up to four players
- [ ] Mobile and console controls

## M4 · Closed alpha

- [ ] Community playtests
- [ ] In-game bug reporting
- [ ] Performance and balance passes

## M5 · Launch

- [ ] Prologue and the first two nations
- [ ] Regular version updates with new heroes, events and story
